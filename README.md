# Grafoterapia — Landing Page

Landing page profesional de grafoterapia (reeducación gráfica).

## Stack
- HTML + CSS (single-file, zero dependencies frontend)
- Express.js (server)
- Docker → EasyPanel

## Desarrollo local
```bash
npm install
node server.js
# http://localhost:80
```

## Deploy
Push a `main` → EasyPanel auto-deploy via GitHub.
